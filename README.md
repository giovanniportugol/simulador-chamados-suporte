# Simulador Inteligente de Atendimento Help Desk

Projeto acadêmico desenvolvido em Python como parte dos meus estudos em Análise e Desenvolvimento de Sistemas.

## Sobre o projeto

Este projeto tem como objetivo simular uma solução inicial de atendimento Help Desk, utilizando lógica de programação e regras simples para analisar descrições de problemas informadas pelo usuário.

A proposta é representar, de forma prática e didática, como um chamado de suporte pode ser registrado, classificado e encaminhado conforme o tipo de problema relatado.

Mesmo sendo um projeto acadêmico, a estrutura busca se aproximar de uma situação real de atendimento em TI, trabalhando conceitos como organização de informações, priorização de demandas, resolução de problemas e resposta inicial ao cliente.

## Objetivo

Demonstrar minha evolução nos estudos de programação e suporte técnico, aplicando Python em uma solução prática voltada ao atendimento de usuários, registro de chamados e análise inicial de problemas.
